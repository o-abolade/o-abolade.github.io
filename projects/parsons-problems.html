Simulating Learners with GPT-4 for Parsons Problems

Exploring how generative models can help investigate learner behavior in programming education.

FocusAI in education · Language models

StatusSelected project

This project examines the use of GPT-4 to simulate learner interactions with Parsons Problems, a programming exercise format built around arranging code fragments into a correct solution.

It explores the promise and limitations of using generative models as a tool for studying possible learner strategies, errors, and responses in computing education.
